# Локальная база AVR для агента — 24.09.2026

Подготовлена версия `attiny162x/1.1.0` для **ATtiny1624, ATtiny1626 и ATtiny1627**. Она продолжает переход к совместному холсту: агент использует требования пользователя, готовые рецепты и локальные источники, затем формирует C, YAML и документацию на языке пользователя.

## Что сделано

- Сохранены полные официальные исходники: даташит **DS40002234B** (575 страниц), errata **DS80000902F** (16 страниц) и **ATtiny DFP 3.4.278**. Для каждого зафиксированы URL, версия, размер и SHA-256. Вместе исходники занимают около 41 МБ и входят в поставку backend.
- Из PDF получены все **591 страница и 914 разделов**, таблицы, кандидаты формул, ограничений и подписи к рисункам. Каждый фрагмент связан с исходным документом и страницей. Полные схемы и исходная вёрстка сохранены в PDF.
- Из DFP извлечены регистры, битовые поля, значения, экземпляры периферии и их адреса для трёх МК; отдельно сохранён небольшой набор фактов для генерации.
- Вручную по исходным страницам проверены **33 факта**: все 10 silicon errata Rev. E, 5 разделов уточнений и 18 важных для рецептов формул, таблиц и ограничений. Автоматическое извлечение остальных страниц явно отделено от проверенных фактов.
- Обновлены **7 рецептов на основе 10 учебных минипроектов**. Сохранена связь с оригинальным кодом; учтены CCP, W1C, порядок чтения UART, расчёт таймеров/baud, владение буферами, OSCLOCK и SFDEN. Указаны условия частоты по питанию, температуре и FREQSEL. Старые неполные HTML-выжимки удалены из активной базы.
- Агент получил один инструмент для каталога, поиска, чтения страниц и обращения к DFP. Интернет допускается только после поиска по всем локальным документам и объяснения оставшегося пробела: максимум 2 внешних запроса, только разрешённые официальные страницы. Локальная база работает и при полностью отключённом внешнем поиске.

## Проверки и границы

Полное извлечение воспроизведено из сохранённых оригиналов без сети; проверены хеши, страницы, связи и соответствие выбранных фактов DFP. Пройдены **214 тестов проекта и 12 тестов Markdown**, включая локальное получение данных, ограничения внешнего доступа и сквозной вызов инструмента из сервиса агента. Составной пример, использующий семь рецептов, скомпилирован для всех трёх МК через **XC8 3.10**.

На сервере компилятор использует **DFP 3.3.272**, справочная база — **3.4.278**. Совместимость выбранных общих символов проверена; это не утверждение о совпадении всех заголовков. Каждый новый сгенерированный проект по-прежнему проходит отдельную компиляцию. Новых аппаратных испытаний не проводилось.

Проверенная генерация пока охватывает GPIO, тактирование, TCA normal overflow и UART/printf/передачу по прерыванию. Наличие полной документации ещё не означает готовность генерации ADC, SPI, TWI, PWM или любого AVR. Для расширения нужны отдельные рецепты, проверки ресурсов, компиляция и при необходимости испытания на плате. Все таблицы и рисунки даташита вручную не проверялись.

База готовится один раз для выбранных версий, а сервер использует её без повторного преобразования PDF. Повторная подготовка нужна при обновлении источников или расширении покрытия; переданный модели контекст всё равно расходует API-токены.

## Где находятся файлы

- `backend/ai/knowledge/attiny162x/1.1.0/reference/raw/` — полные оригиналы.
- `reference/sources.json`, `corpus.json`, `dfp-registers.json`, `reviewed-facts.json` внутри этой версии — происхождение, структурированный справочник и проверенные факты.
- `recipes/*/SKILL.md`, `manifest.json`, `compiler-evidence.json` — рецепты, контроль целостности и результаты компиляции.
- `scripts/avr-knowledge/` — воспроизводимая обработка и проверки. Подробные команды: [README базы](../backend/ai/knowledge/README.md).

## Что с HTML Microchip

Получить WebHelp ZIP не удалось: официальный HTML-сервис возвращал HTTP 503 с Reference #102. Утверждать, что HTML удалён или недоступен всем, оснований нет. Есть исторические жалобы: [недоступные документы и сломанные ссылки, 2023](https://forum.allaboutcircuits.com/threads/microchip-forum-is-it-really-an-improvement-not.192486/), [ошибки загрузки datasheet/errata, 2021](https://protoncompiler.com/index.php?topic=283.0), [изменившиеся адреса документации, 2025](https://github.com/zephyrproject-rtos/zephyr/issues/88009). Независимого подтверждения именно текущего сбоя найти не удалось. Рабочая база поэтому построена на доступных официальных PDF и DFP.
