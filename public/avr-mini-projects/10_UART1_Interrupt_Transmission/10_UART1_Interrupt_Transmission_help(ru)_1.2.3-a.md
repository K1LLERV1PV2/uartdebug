Передача через UART1 с использованием прерываний

## Short Project Description
Краткое описание проекта

Неблокирующая передача буфера через UART1 с использованием прерывания освобождения регистра данных.

## Full Mini-Project Description
Полное описание мини-проекта

Этот мини-проект демонстрирует передачу через UART1 с использованием прерываний.

Это версия проекта 09 для UART1. Механизм передачи работает так же, но в этом проекте используются `USART1` и вывод передачи UART1 `PA1`.

Главная программа запускает передачу вызовом:

```c
USART_SendBuffer(uint8_t *buffer, uint8_t length)
```

После этого прерывание UART1 Data Register Empty передаёт байты по одному.

Обработчик прерывания хранит:

- указатель на текущий байт;
- количество байтов, которые ещё нужно передать.

После загрузки последнего байта в передатчик UART прерывание DRE запрещается.

Пример в `main()` использует `snprintf()` для формирования в `tx_buffer` текста:

```text
Register = 0x1234
```

Затем передача буфера запускается функцией `USART_SendBuffer()`. Пример повторяется приблизительно каждые 200 мс.

Вызов `_delay_ms(200)` по-прежнему блокирует главный цикл во время задержки. Однако сама передача UART после запуска выполняется по прерываниям независимо от главной программы.

Формат UART:

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

Обычная запись:

```text
115200 8N1
```

Проект также содержит повторно используемые вспомогательные функции для передачи 16-битных и 32-битных значений в выбранном порядке байтов.

## Hardware Requirements and Setup
Требования к оборудованию и подключение

В предполагаемой схеме используются два адаптера USB-UART:

- один адаптер для программирования по UPDI;
- второй адаптер для приёма и отображения данных UART1.

Подключение второго адаптера:

```text
Microcontroller PA1 / TxD  ->  USB-UART RxD
Microcontroller GND        ->  USB-UART GND
```

Микроконтроллер и принимающий адаптер USB-UART должны использовать одинаковый уровень логического напряжения.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14:

```text
PA1 / UART1 TxD  ->  pin 11
PA2 / UART1 RxD  ->  pin 12
```

Приём UART1 в этом мини-проекте не используется.

### Verification
Проверка

Если текст появляется повторно, а байты передаются обработчиком прерывания UART1 DRE, передача по прерываниям работает правильно.

Это проверяет:

- конфигурацию UART1;
- `PA1` как выход `TxD` UART1;
- разрешение глобальных прерываний;
- работу прерывания UART1 Data Register Empty;
- передачу буфера через `USART_SendBuffer()`;
- запрещение прерывания после последнего байта;
- аппаратное подключение к принимающему адаптеру USB-UART.

## What This Mini-Project Is For
Для чего предназначен этот мини-проект

Этот мини-проект предоставляет версию повторно используемого механизма передачи по прерываниям из проекта 09 для UART1.

Главная цель — использовать тот же неблокирующий способ передачи, когда UART0 уже занят или требуется второй последовательный канал.

Тот же механизм передачи можно повторно использовать для:

- форматированных диагностических строк;
- периодического отладочного вывода;
- наблюдения двоичных переменных;
- данных датчиков;
- пакетов данных;
- более крупных прикладных функций передачи.

## Usage Options
Варианты использования

Можно:

- сформировать текстовую строку в `tx_buffer` с помощью `snprintf()` и передать её через `USART_SendBuffer()`;
- передать значение `uint16_t` старшим байтом вперёд с помощью `send_uint16_High_Low()`;
- передать значение `uint32_t` старшим байтом вперёд с помощью `send_uint32_High_Low()`;
- передать значение `uint16_t` в порядке little-endian с помощью `send_uint16_Low_High()`;
- передать другой существующий буфер, указав его адрес и длину в `USART_SendBuffer()`;
- создать дополнительные вспомогательные функции для других типов переменных или форматов пакетов;
- использовать UART0 и UART1 для разных задач в более крупном проекте.

## Common Mistakes
Распространённые ошибки

- Не вызвать `sei()`.
- Забыть, что `USART_SendBuffer()` запускает передачу разрешением прерывания DRE.
- Запустить новую передачу до завершения предыдущей.
- Изменить `tx_buffer`, пока он ещё передаётся.
- Передать буфер, который перестанет существовать до завершения передачи.
- Передать нулевую длину в текущую реализацию `USART_SendBuffer()`.
- Изменить ISR без сохранения логики указателя, счётчика байтов и запрещения прерывания.
- Подключить принимающий адаптер к `PB2` вместо `PA1`.
- Подключить `TxD` микроконтроллера к `TxD` адаптера вместо `RxD`.
- Забыть общий `GND`.
- Выбрать неправильную скорость передачи или COM-порт.

## Code Description
Описание кода

### Main Compiler Header
Основной заголовочный файл компилятора

`#include <xc.h>` предоставляет определения регистров и битов конкретного устройства для XC8.

### CPU Clock Definition
Определение частоты процессора

```c
#define F_CPU 3333333UL
```

`F_CPU` используется библиотекой задержек и при расчёте скорости UART.

При заводских настройках тактирования частота процессора составляет приблизительно 3,333 МГц.

Эта директива не настраивает аппаратную частоту.

### Delay Library
Библиотека задержек

```c
#include <util/delay.h>
```

Этот заголовочный файл предоставляет `_delay_ms()` и `_delay_us()`.

Текущий пример использует `_delay_ms(200)` между запросами передачи.

### Interrupt Library
Библиотека прерываний

```c
#include <avr/interrupt.h>
```

Этот заголовочный файл предоставляет макросы прерываний, используемые в проекте, включая `ISR(...)` и `sei()`.

### Standard I/O Library
Стандартная библиотека ввода-вывода

```c
#include <stdio.h>
```

Этот заголовочный файл предоставляет `snprintf()`.

### User-Defined UART Parameters
Параметры UART, задаваемые пользователем

```c
#define BAUD_RATE 115200UL
#define CLK_PER   F_CPU
```

`BAUD_RATE` задаёт скорость UART.

`CLK_PER` — частота периферийного тактирования, используемая при расчёте скорости. Здесь она равна `F_CPU`.

### USART Baud Register Calculation
Расчёт регистра скорости USART

```c
#define USART_BAUD_RATE \
    ((uint16_t)(((float)CLK_PER * 64.0 / (16.0 * (float)BAUD_RATE)) + 0.5))
```

Это выражение рассчитывает значение, записываемое в `USART1.BAUD`.

### USART1 Initialization
Инициализация USART1

Функция `USART_Init()` настраивает UART1 для передачи по прерываниям.

#### UART Frame Format
Формат кадра UART

Присваивание `USART1.CTRLC` выбирает асинхронный режим, отсутствие чётности, 8 бит данных и 1 стоповый бит: `8N1`.

#### USART Baud Rate Register
Регистр скорости USART

```c
USART1.BAUD = USART_BAUD_RATE;
```

Этот регистр настраивает генератор скорости USART. При текущей частоте тактирования и значении `BAUD_RATE` обеспечивается скорость приблизительно 115200 бод.

#### UART1 TxD Pin Configuration
Настройка вывода TxD UART1

```c
PORTA.DIRSET = PIN1_bm;
```

PA1 настраивается как выход передачи UART1.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PA1` находится на выводе 11.

UART1 `RxD` — `PA2`, вывод 12 в том же корпусе, но в этом проекте он не используется.

#### USART Transmitter Enable
Разрешение передатчика USART

```c
USART1.CTRLB = USART_TXEN_bm;
```

Эта операция разрешает передатчик USART1.

Само прерывание DRE разрешается функцией `USART_SendBuffer()` только при запуске передачи.

### Transmission State Variables
Переменные состояния передачи

```c
static volatile uint8_t current_tx_byte_count;
static volatile uint8_t *current_tx_ptr;
```

Эти переменные описывают текущую передачу, обрабатываемую ISR.

`current_tx_byte_count` содержит количество байтов, которые ещё необходимо загрузить в передатчик.

`current_tx_ptr` указывает на текущий байт активного буфера.

### Transmission Buffer
Буфер передачи

```c
uint8_t tx_buffer[100];
```

Этот глобальный буфер используется примером с `snprintf()` и предоставленными вспомогательными функциями.

Поскольку буфер глобальный, он остаётся существовать во время передачи по прерываниям.

### UART1 Data Register Empty ISR
Обработчик прерывания освобождения регистра данных UART1

```c
ISR(USART1_DRE_vect)
```

Этот обработчик прерывания выполняет побайтовую передачу.

Прерывание DRE возникает, когда регистр данных передатчика UART1 готов принять следующий байт.

### Byte Transmission
Передача байта

```c
USART1.TXDATAL = *current_tx_ptr;
```

Эта операция загружает текущий байт в регистр данных передатчика USART1.

### Transmission Pointer Advance
Переход указателя к следующему байту

```c
current_tx_ptr++;
```

После передачи байта указатель переходит к следующему байту активного буфера.

### Remaining Byte Count
Счётчик оставшихся байтов

```c
current_tx_byte_count--;
```

После каждого переданного байта счётчик оставшихся байтов уменьшается.

### DRE Interrupt Disable
Запрещение прерывания DRE

```c
USART1.CTRLA &= ~USART_DREIE_bm;
```

Когда счётчик оставшихся байтов достигает нуля, прерывание DRE запрещается.

### Buffer Transmission Start
Запуск передачи буфера

```c
void USART_SendBuffer(uint8_t *buffer, uint8_t length)
```

Эта функция запускает передачу буфера.

Она сохраняет количество байтов и адрес буфера, а затем разрешает прерывание UART1 DRE:

```c
USART1.CTRLA |= USART_DREIE_bm;
```

Текущая реализация не проверяет, продолжается ли предыдущая передача.

Необходимо передавать ненулевое значение `length`.

### High-Byte-First uint16 Transmission
Передача uint16 старшим байтом вперёд

```c
send_uint16_High_Low()
```

Эта вспомогательная функция помещает 16-битное значение в `tx_buffer` старшим байтом вперёд.

Пример:

```text
0x1234 -> 12 34
```

### High-Byte-First uint32 Transmission
Передача uint32 старшим байтом вперёд

```c
send_uint32_High_Low()
```

Эта вспомогательная функция помещает 32-битное значение в `tx_buffer` старшим байтом вперёд.

Пример:

```text
0x12345678 -> 12 34 56 78
```

### Little-Endian uint16 Transmission
Передача uint16 в порядке little-endian

```c
send_uint16_Low_High()
```

Эта вспомогательная функция помещает 16-битное значение в `tx_buffer` младшим байтом вперёд.

Пример:

```text
0x1234 -> 34 12
```

### The Entry Point
Точка входа

`int main(void)` — точка входа программы.

### USART1 Initialization Call
Вызов инициализации USART1

```c
USART_Init();
```

UART1 настраивается до использования передачи по прерываниям.

### Global Interrupt Enable
Разрешение глобальных прерываний

```c
sei();
```

Глобальные прерывания должны быть разрешены до выполнения прерывания UART1 DRE.

### Main Infinite Loop
Главный бесконечный цикл

Цикл `while (1)` повторно подготавливает и запускает пример передачи.

### snprintf Message Construction
Формирование сообщения функцией snprintf

```c
tx_byte_count = snprintf((char *)tx_buffer,
                         (size_t)sizeof(tx_buffer),
                         "Register = 0x%X\r\n",
                         0x1234);
```

`snprintf()` преобразует форматированный текст в байты, сохраняемые в `tx_buffer`, и возвращает длину текста.

В текущем фиксированном примере полученный текст легко помещается в 100-байтовый буфер.

### Buffer Transmission Request
Запрос передачи буфера

```c
USART_SendBuffer(tx_buffer, tx_byte_count);
```

Эта операция запускает передачу подготовленного текста по прерываниям.

### Transmission Interval
Интервал передачи

```c
_delay_ms(200);
```

Пример ожидает приблизительно 200 мс перед подготовкой следующей передачи.

Эта задержка блокирует главный цикл, но не выполняет побайтовую передачу UART.
