# 06_UART_Basic_Receive
Базовый приём данных через UART

## File Version
Версия файла

## Short Project Description
Краткое описание проекта

Базовый приём байта через UART0 и передача ответа с использованием опроса состояния.

## Full Mini-Project Description
Полное описание мини-проекта

Этот мини-проект инициализирует UART0 для двустороннего обмена данными.

Микроконтроллер ожидает приёма одного байта через UART0. Затем он считывает принятый байт, увеличивает его значение на `1`, ожидает готовности буфера передачи принять новый байт и отправляет результат обратно через UART0.

В проекте используется приём и передача UART с опросом состояния. Главный цикл блокируется во время ожидания принятого байта и также может ожидать готовности передатчика.

Формат UART:

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

Обычная запись:

```text
115200 8N1
```

Передаваемые и принимаемые данные можно наблюдать в разделе UART сайта **uartdebug.com**.

## Hardware Requirements and Setup
Требования к оборудованию и подключение

В предполагаемой схеме используются два адаптера USB-UART:

- один адаптер для программирования по UPDI;
- второй адаптер для двустороннего обмена данными через UART0 с работающей программой.

Подключение второго адаптера:

```text
Microcontroller PB2 / TxD  ->  USB-UART RxD
Microcontroller PB3 / RxD  <-  USB-UART TxD
Microcontroller GND        ->  USB-UART GND
```

Микроконтроллер и второй адаптер USB-UART должны использовать одинаковый уровень логического напряжения.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14:

```text
PB2 / UART0 TxD  ->  pin 7
PB3 / UART0 RxD  ->  pin 6
```

В этом мини-проекте необходимы и `TxD`, и `RxD`, поскольку данные передаются в обоих направлениях.

### Verification
Проверка

Если каждый переданный байт возвращается со значением, увеличенным на `1`, приём и передача UART0 работают правильно.

Это проверяет:

- приём UART0;
- передачу UART0;
- аппаратные соединения `TxD` и `RxD`;
- двусторонний обмен через UART.

## What This Mini-Project Is For
Для чего предназначен этот мини-проект

Этот мини-проект демонстрирует:

- инициализацию UART0 для приёма и передачи;
- опрос флага завершения приёма;
- чтение одного байта из `USART0.RXDATAL`;
- опрос флага готовности буфера передачи;
- запись одного байта в `USART0.TXDATAL`;
- простейший блокирующий двусторонний обмен через UART.

Это естественный следующий шаг после проекта 05, который демонстрирует только передачу UART.

## Usage Options
Варианты использования

Можно:

- передавать разные значения байтов и наблюдать возвращаемый результат;
- использовать режим HEX для наблюдения необработанных значений байтов;
- заменить `received_byte + 1` другой простой операцией, например `received_byte + 2`;
- выбрать другую поддерживаемую стандартную скорость передачи; при изменении скорости также измените настройку UART на сайте **uartdebug.com**;
- использовать UART1 вместо UART0; для этого требуется изменить код и подключить второй адаптер к выводам UART1;
- изменить частоту CPU, как показано в проекте 02; обновите `F_CPU` в этом проекте в соответствии с новой частотой.

## Common Mistakes
Распространённые ошибки

- Подключение `TxD` микроконтроллера к `TxD` адаптера вместо `RxD`.
- Подключение `RxD` микроконтроллера к `RxD` адаптера вместо `TxD`.
- Отсутствие общего `GND`.
- Использование разных уровней логического напряжения.
- Выбор неправильного COM-порта.
- Выбор одного и того же COM-порта для обоих адаптеров.
- Выбор неправильной скорости передачи.

## Code Description
Описание кода

### Main Compiler Header
Основной заголовочный файл компилятора

`#include <xc.h>` предоставляет определения регистров и битов конкретного устройства для XC8.

### CPU Clock Definition
Определение частоты процессора

```c
#define F_CPU 3333333UL
```

`F_CPU` используется при расчёте скорости UART.

При заводских настройках тактирования частота процессора составляет приблизительно 3,333 МГц.

Эта директива не настраивает аппаратную частоту.

### Delay Library
Библиотека задержек

```c
#include <util/delay.h>
```

Этот заголовочный файл предоставляет `_delay_ms()` и `_delay_us()`.

Текущая программа не вызывает эти функции задержки, но заголовочный файл сохранён в предоставленной структуре проекта.

`F_CPU` должна быть определена до подключения этого заголовочного файла.

### User-Defined UART Parameters
Параметры UART, задаваемые пользователем

```c
#define BAUD_RATE 115200UL
#define CLK_PER   F_CPU
```

`BAUD_RATE` выбирается пользователем.

`CLK_PER` — частота периферийного тактирования, используемая при расчёте скорости. Здесь она равна `F_CPU`.

### USART Baud Register Calculation
Расчёт регистра скорости USART

```c
#define USART_BAUD_RATE \
    ((uint16_t)(((float)CLK_PER * 64.0 / (16.0 * (float)BAUD_RATE)) + 0.5))
```

Это выражение рассчитывает значение, записываемое в `USART0.BAUD`.

Вычисление с плавающей точкой и добавление `0.5` округляют результат до ближайшего целого.

### USART0 Initialization
Инициализация USART0

Функция `USART_Init()` настраивает UART0 до начала приёма и передачи.

#### UART Frame Format
Формат кадра UART

Присваивание `USART0.CTRLC` выбирает асинхронный режим, отсутствие чётности, 8 бит данных и 1 стоповый бит: `8N1`.

#### USART Baud Rate Register
Регистр скорости USART

```c
USART0.BAUD = USART_BAUD_RATE;
```

Этот регистр настраивает генератор скорости USART. При текущей частоте тактирования и значении `BAUD_RATE` обеспечивается скорость приблизительно 115200 бод.

#### UART0 TxD Pin Configuration
Настройка вывода TxD UART0

```c
PORTB.DIRSET = PIN2_bm;
```

PB2 настраивается как выход передачи UART0.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PB2` находится на выводе 7.

UART0 `RxD` — это `PB3`, вывод 6 в том же корпусе. Он используется как вход приёма.

#### USART Transmitter and Receiver Enable
Разрешение передатчика и приёмника USART

```c
USART0.CTRLB = USART_TXEN_bm | USART_RXEN_bm;
```

Эта операция разрешает и передатчик, и приёмник USART0.

### UART1 Initialization Note
Примечание об инициализации UART1

Для преобразования примера в UART1:

1. Замените `USART0.` на `USART1.`.
2. Замените `PORTB.DIRSET = PIN2_bm;` на `PORTA.DIRSET = PIN1_bm;`.

Для предполагаемых микроконтроллеров tinyAVR 2-series в корпусах SOIC-14:

```text
PA1 / UART1 TxD  ->  pin 11
PA2 / UART1 RxD  ->  pin 12
```

### The Entry Point
Точка входа

`int main(void)` — точка входа программы.

### Received Byte Variable
Переменная принятого байта

```c
uint8_t received_byte;
```

Эта переменная хранит байт, считанный из регистра данных приёмника USART0.

### USART0 Initialization Call
Вызов инициализации USART0

```c
USART_Init();
```

UART0 настраивается до запуска главного цикла.

### Main Infinite Loop
Главный бесконечный цикл

Цикл `while (1)` непрерывно повторяет операцию приёма и передачи ответа.

### Receive Complete Check
Проверка завершения приёма

```c
while (!(USART0.STATUS & USART_RXCIF_bm))
{
    ;
}
```

Этот цикл опроса ожидает, пока USART0 не примет байт.

Поскольку цикл блокирующий, CPU остаётся здесь до появления байта.

### Received Byte Read
Чтение принятого байта

```c
received_byte = USART0.RXDATAL;
```

Эта операция считывает принятый байт из регистра данных приёмника USART0.

### Data Register Empty Check
Проверка освобождения регистра данных

```c
while (!(USART0.STATUS & USART_DREIF_bm))
{
    ;
}
```

Этот цикл опроса ожидает, пока буфер передачи сможет принять следующий байт.

### Incremented Byte Transmission
Передача увеличенного байта

```c
USART0.TXDATAL = received_byte + 1;
```

Эта операция увеличивает значение принятого байта на `1` и записывает результат в регистр данных передатчика USART0.

Область применения
