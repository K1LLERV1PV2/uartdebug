Краткое описание проекта

## Full Mini-Project Description
Полное описание мини-проекта

Этот мини-проект вводит передачу через UART0 с использованием прерываний.

Прикладной код запускает передачу вызовом:

```c
USART_SendBuffer(uint8_t *buffer, uint8_t length)
```

После этого прерывание UART0 Data Register Empty передаёт буфер по одному байту. Главная программа не ожидает физической передачи каждого байта UART.

Обработчик прерывания хранит указатель на текущий байт и количество оставшихся байтов. После загрузки последнего байта в передатчик UART прерывание DRE запрещается.

Пример в `main()` использует `snprintf()` для формирования в `tx_buffer` текста:

```text
Register = 0x1234
```

Новая передача запускается приблизительно каждые 200 мс. Вызов `_delay_ms(200)` по-прежнему блокирует главный цикл во время задержки, но сама побайтовая передача UART выполняется по прерываниям.

Формат UART:

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

Обычная запись:

```text
115200 8N1
```

Проект также содержит повторно используемые вспомогательные функции для передачи 16-битных и 32-битных значений в выбранном порядке байтов.

## Hardware Requirements and Setup
Требования к оборудованию и подключение

В предполагаемой схеме используются два адаптера USB-UART:

- один адаптер для программирования по UPDI;
- второй адаптер для приёма данных UART0.

Подключение второго адаптера:

```text
Microcontroller PB2 / TxD  ->  USB-UART RxD
Microcontroller GND        ->  USB-UART GND
```

Микроконтроллер и принимающий адаптер USB-UART должны использовать одинаковый уровень логического напряжения.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PB2` находится на выводе 7.

Приём UART0 в этом мини-проекте не используется.

## What This Mini-Project Is For
Для чего предназначен этот мини-проект

Этот мини-проект является первым повторно используемым модулем передачи UART по прерываниям в последовательности проектов.

Его главная цель — отделить прикладной код от побайтовой передачи UART. Прикладной код запускает передачу, после чего аппаратный UART и обработчик прерывания передают буфер в фоновом режиме.

Тот же механизм можно использовать для форматированных диагностических строк, наблюдения двоичных переменных, данных датчиков и прикладных пакетов.

## Usage Options
Варианты использования

Можно:

- сформировать текст в `tx_buffer` с помощью `snprintf()` и передать его через `USART_SendBuffer()`;
- передать `uint16_t` старшим байтом вперёд с помощью `send_uint16_High_Low()`;
- передать `uint32_t` старшим байтом вперёд с помощью `send_uint32_High_Low()`;
- передать `uint16_t` в порядке little-endian с помощью `send_uint16_Low_High()`;
- передать другой буфер, указав его адрес и длину в `USART_SendBuffer()`;
- создать дополнительные вспомогательные функции для других типов переменных или форматов пакетов.

## Common Mistakes
Распространённые ошибки

- Не вызвать `sei()`.
- Запустить новую передачу до завершения предыдущей.
- Изменить `tx_buffer`, пока он ещё передаётся.
- Передать буфер, который перестанет существовать до завершения передачи.
- Передать нулевую длину в текущую реализацию `USART_SendBuffer()`.
- Изменить ISR без сохранения логики указателя, счётчика байтов и запрещения прерывания.
- Подключить `TxD` микроконтроллера к `TxD` адаптера вместо `RxD`.
- Забыть общий `GND`.
- Выбрать неправильную скорость передачи или COM-порт.

## Code Description
Описание кода

### Main Compiler Header
Основной заголовочный файл компилятора

`#include <xc.h>` предоставляет определения регистров и битов конкретного устройства для XC8.

### CPU Clock Definition
Определение частоты процессора

`F_CPU` задаёт частоту приблизительно 3,333 МГц и используется библиотекой задержек и при расчёте скорости UART.

### Delay Library
Библиотека задержек

`<util/delay.h>` предоставляет `_delay_ms()`. В текущем примере `_delay_ms(200)` используется между запросами передачи.

### Interrupt Library
Библиотека прерываний

`<avr/interrupt.h>` предоставляет `ISR(...)` и `sei()`.

### Standard I/O Library
Стандартная библиотека ввода-вывода

`<stdio.h>` предоставляет `snprintf()`.

### User-Defined UART Parameters
Параметры UART, задаваемые пользователем

`BAUD_RATE` равен `115200`, а `CLK_PER` равен `F_CPU`.

### USART Baud Register Calculation
Расчёт регистра скорости USART

`USART_BAUD_RATE` рассчитывает значение, записываемое в `USART0.BAUD`.

### USART0 Initialization
Инициализация USART0

`USART_Init()` настраивает UART0 для асинхронной передачи.

#### UART Frame Format
Формат кадра UART

Используется формат `115200 8N1`.

#### USART Baud Rate Register
Регистр скорости USART

`USART0.BAUD = USART_BAUD_RATE;` настраивает генератор скорости передачи.

#### UART0 TxD Pin Configuration
Настройка вывода TxD UART0

`PORTB.DIRSET = PIN2_bm;` настраивает `PB2` как `TxD` UART0.

#### USART Transmitter Enable
Разрешение передатчика USART

`USART0.CTRLB = USART_TXEN_bm;` разрешает передатчик. Прерывание DRE разрешается только при запуске передачи.

### Transmission State Variables
Переменные состояния передачи

`current_tx_byte_count` хранит количество оставшихся байтов, а `current_tx_ptr` указывает на текущий байт буфера.

### Transmission Buffer
Буфер передачи

`tx_buffer[100]` — глобальный буфер, используемый примерами и вспомогательными функциями.

### UART0 Data Register Empty ISR
Обработчик прерывания освобождения регистра данных UART0

`ISR(USART0_DRE_vect)` выполняет побайтовую передачу.

### Byte Transmission
Передача байта

`USART0.TXDATAL = *current_tx_ptr;` загружает текущий байт в передатчик UART.

### Transmission Pointer Advance
Переход указателя к следующему байту

`current_tx_ptr++;` переводит указатель на следующий байт.

### Remaining Byte Count
Счётчик оставшихся байтов

`current_tx_byte_count--;` уменьшает количество оставшихся байтов.

### DRE Interrupt Disable
Запрещение прерывания DRE

Когда счётчик достигает нуля, `USART0.CTRLA &= ~USART_DREIE_bm;` запрещает прерывание DRE.

### Buffer Transmission Start
Запуск передачи буфера

`USART_SendBuffer()` сохраняет адрес буфера и его длину, а затем разрешает прерывание DRE.

### High-Byte-First uint16 Transmission
Передача uint16 старшим байтом вперёд

`send_uint16_High_Low()` передаёт `0x1234` как `12 34`.

### High-Byte-First uint32 Transmission
Передача uint32 старшим байтом вперёд

`send_uint32_High_Low()` передаёт `0x12345678` как `12 34 56 78`.

### Little-Endian uint16 Transmission
Передача uint16 в порядке little-endian

`send_uint16_Low_High()` передаёт `0x1234` как `34 12`.

### The Entry Point
Точка входа

`int main(void)` — точка входа программы.

### USART0 Initialization Call
Вызов инициализации USART0

`USART_Init()` вызывается до использования передачи по прерываниям.

### Global Interrupt Enable
Разрешение глобальных прерываний

`sei()` разрешает глобальные прерывания.

### Main Infinite Loop
Главный бесконечный цикл

Главный цикл повторно подготавливает и запускает пример передачи.

### snprintf Message Construction
Формирование сообщения функцией snprintf

`snprintf()` формирует текст в `tx_buffer` и возвращает его длину.

### Buffer Transmission Request
Запрос передачи буфера

`USART_SendBuffer(tx_buffer, tx_byte_count);` запускает передачу подготовленного текста по прерываниям.

### Transmission Interval
Интервал передачи

`_delay_ms(200);` создаёт интервал между примерами передачи. Эта задержка блокирует главный цикл, но не выполняет побайтовую передачу UART.

### Application Scope
Область применения

Этот мини-проект предназначен для микроконтроллеров tinyAVR 2-series с совместимыми регистрами USART0, прерываний и маршрутизации выводов.
