# 05_UART_Basic_Transmission
Базовая передача данных через UART

## File Version
Версия файла

Version 1.2.3-c

## Short Project Description
Краткое описание проекта

Базовая передача байтов через UART0 с опросом состояния и блокирующей задержкой между передаваемыми байтами.

## Full Mini-Project Description
Полное описание мини-проекта

Этот мини-проект инициализирует UART0 и передаёт один байт приблизительно каждые 20 мс.

После каждой передачи значение байта увеличивается. После `255` значение типа `uint8_t` автоматически возвращается к `0`, создавая повторяющуюся пилообразную последовательность от `0` до `255`.

В проекте используется передача UART с опросом состояния. Перед записью в `USART0.TXDATAL` программа ожидает, пока буфер передачи сможет принять следующий байт.

Интервал 20 мс создаётся функцией `_delay_ms(20)`, поэтому во время этой задержки главный цикл заблокирован.

Формат UART:

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

Обычная запись:

```text
115200 8N1
```

Передаваемые данные можно наблюдать в разделе UART сайта **uartdebug.com**.

## Hardware Requirements and Setup
Требования к оборудованию и подключение

В предполагаемой схеме используются два адаптера USB-UART:

- один адаптер для программирования по UPDI;
- второй адаптер для наблюдения передачи UART0.

Подключение второго адаптера:

```text
Microcontroller PB2 / TxD  ->  USB-UART RxD
Microcontroller GND        ->  USB-UART GND
```

Микроконтроллер и принимающий адаптер USB-UART должны использовать одинаковый уровень логического напряжения.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PB2` находится на выводе 7.

Вывод `RxD` микроконтроллера не используется. Для наблюдения передачи подключите только `TxD` и общий `GND`.

## What This Mini-Project Is For
Для чего предназначен этот мини-проект

Этот мини-проект демонстрирует:

- инициализацию UART0;
- непосредственную передачу одного байта;
- опрос флага готовности буфера передачи;
- запись в `USART0.TXDATAL`;
- создание повторяющейся последовательности байтов;
- наблюдение необработанных данных UART в графическом и HEX-виде.

Это простейшая практическая проверка передачи перед проектами UART с использованием прерываний.

## Usage Options
Варианты использования

Можно:

- сформировать последовательность передаваемых данных, отличающуюся от используемой в этом проекте пилообразной последовательности;
- выбрать другую поддерживаемую стандартную скорость передачи; при изменении скорости также измените настройку скорости приёма в разделе UART сайта **uartdebug.com**;
- использовать UART1 вместо UART0; для этого требуется изменить код и подключить второй адаптер к другому выходу микроконтроллера;
- изменить частоту CPU, как показано в проекте 02; обновите `F_CPU` в этом проекте в соответствии с новой частотой.

## Common Mistakes
Распространённые ошибки

- Подключение `TxD` к `TxD` адаптера вместо `RxD`.
- Отсутствие общего `GND`.
- Использование разных уровней логического напряжения.
- Выбор неправильного COM-порта.
- Выбор неправильной скорости передачи.
- Игнорирование того, что `_delay_ms(20)` блокирует главный цикл.

## Code Description
Описание кода

### Main Compiler Header
Основной заголовочный файл компилятора

`#include <xc.h>` предоставляет определения регистров и битов конкретного устройства для XC8.

### CPU Clock Definition
Определение частоты процессора

```c
#define F_CPU 3333333UL
```

`F_CPU` используется библиотекой задержек и при расчёте скорости UART.

При заводских настройках тактирования частота процессора составляет приблизительно 3,333 МГц.

Эта директива не настраивает аппаратную частоту.

### Delay Library
Библиотека задержек

```c
#include <util/delay.h>
```

Этот заголовочный файл предоставляет `_delay_ms()` и `_delay_us()`.

`F_CPU` должна быть определена до подключения этого заголовочного файла.

### User-Defined UART Parameters
Параметры UART, задаваемые пользователем

```c
#define BAUD_RATE 115200UL
#define CLK_PER   F_CPU
```

`BAUD_RATE` выбирается пользователем.

`CLK_PER` — частота периферийного тактирования, используемая при расчёте скорости. Здесь она равна `F_CPU`.

### USART Baud Register Calculation
Расчёт регистра скорости USART

```c
#define USART_BAUD_RATE     ((uint16_t)(((float)CLK_PER * 64.0 / (16.0 * (float)BAUD_RATE)) + 0.5))
```

Это выражение рассчитывает значение, записываемое в `USART0.BAUD`.

Вычисление с плавающей точкой и добавление `0.5` округляют результат до ближайшего целого.

### USART0 Initialization
Инициализация USART0

Функция `USART_Init()` настраивает UART0 до начала передачи.

#### UART Frame Format
Формат кадра UART

Присваивание `USART0.CTRLC` выбирает асинхронный режим, отсутствие чётности, 8 бит данных и 1 стоповый бит: `8N1`.

#### USART Baud Rate Register
Регистр скорости USART

```c
USART0.BAUD = USART_BAUD_RATE;
```

Этот регистр настраивает генератор скорости USART. При текущей частоте тактирования и значении `BAUD_RATE` обеспечивается скорость приблизительно 115200 бод.

#### UART0 TxD Pin Configuration
Настройка вывода TxD UART0

```c
PORTB.DIRSET = PIN2_bm;
```

PB2 настраивается как выход передачи UART0.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PB2` находится на выводе 7.

#### USART Transmitter Enable
Разрешение передатчика USART

```c
USART0.CTRLB = USART_TXEN_bm;
```

Эта операция разрешает передатчик USART0.

### UART1 Initialization Note
Примечание об инициализации UART1

Для преобразования примера в UART1:

1. Замените `USART0.` на `USART1.`.
2. Замените `PORTB.DIRSET = PIN2_bm;` на `PORTA.DIRSET = PIN1_bm;`.

Для предполагаемых микроконтроллеров tinyAVR 2-series в корпусе SOIC-14 сигнал `TxD` UART1 находится на `PA1`, вывод 11.

### The Entry Point
Точка входа

`int main(void)` — точка входа программы.

### Output Data Variable
Переменная выходных данных

```c
uint8_t out_data = 0;
```

Эта переменная хранит следующий передаваемый байт. После `255` она автоматически переходит к `0`.

### USART0 Initialization Call
Вызов инициализации USART0

```c
USART_Init();
```

UART0 настраивается до запуска главного цикла.

### Main Infinite Loop
Главный бесконечный цикл

Цикл `while (1)` непрерывно повторяет последовательность передачи.

### Data Register Empty Check
Проверка освобождения регистра данных

```c
while (!(USART0.STATUS & USART_DREIF_bm))
{
    ;
}
```

Этот цикл опроса ожидает, пока буфер передачи сможет принять следующий байт.

При интервале 20 мс буфер обычно уже готов, однако проверка сохраняет правильную работу при уменьшении интервала.

### Byte Transmission
Передача байта

```c
USART0.TXDATAL = out_data;
```

Эта операция помещает один байт в буфер передачи USART.

### Output Data Increment
Увеличение выходных данных

```c
out_data++;
```

Передаваемая последовательность повторяется от `0` до `255`.

### Transmission Interval
Интервал передачи

```c
_delay_ms(20);
```

Эта функция создаёт интервал приблизительно 20 мс между байтами и блокирует главный цикл.

При `115200 8N1` физическая передача одного байта занимает приблизительно 87 мкс.

### Application Scope
Область применения

Этот мини-проект предназначен для микроконтроллеров tinyAVR 2-series с совместимыми регистрами USART и маршрутизации выводов.
