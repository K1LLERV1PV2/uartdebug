# 08_Printf_Redirect_USART1
Перенаправление printf в UART1

## File Version
Версия файла

Version 1.2.3-a

## Short Project Description
Краткое описание проекта

Перенаправление вывода `printf()` в UART1 для блокирующей передачи форматированного текста.

## Full Mini-Project Description
Полное описание мини-проекта

Этот мини-проект инициализирует UART1 и перенаправляет в него стандартный поток C `stdout`.

После перенаправления текст, формируемый функцией `printf()`, передаётся через UART1. В примере каждые 500 мс передаётся увеличивающийся счётчик:

```text
Counter = 0
Counter = 1
Counter = 2
...
```

В проекте используется блокирующая передача UART. Каждый символ, сформированный `printf()`, передаётся функции `USART_PrintChar()`, которая ожидает готовности буфера USART принять следующий байт, а затем записывает символ в `USART1.TXDATAL`.

Формат UART:

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

Обычная запись:

```text
115200 8N1
```

Получаемый текст можно наблюдать в разделе UART сайта **uartdebug.com**.

## Relationship to Project 07
Связь с проектом 07

Проект 07 перенаправляет `printf()` через UART0. Проект 08 использует тот же блокирующий способ перенаправления `printf()` через UART1.

| Item | Project 07 | Project 08 |
|---|---|---|
| UART peripheral | USART0 | USART1 |
| TxD pin | PB2 | PA1 |
| SOIC-14 pin | 7 | 11 |
| Output method | `printf()` | `printf()` |
| Interrupts | No | No |
| Transmission type | Blocking | Blocking |

## Hardware Requirements and Setup
Требования к оборудованию и подключение

В предполагаемой схеме используются два адаптера USB-UART:

- один адаптер для программирования по UPDI;
- второй адаптер для приёма и отображения текста UART1, формируемого `printf()`.

Подключение второго адаптера:

```text
Microcontroller PA1 / TxD  ->  USB-UART RxD
Microcontroller GND        ->  USB-UART GND
```

Микроконтроллер и принимающий адаптер USB-UART должны использовать одинаковый уровень логического напряжения.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PA1` находится на выводе 11.

Вывод `RxD` микроконтроллера в этом мини-проекте не используется.

## What This Mini-Project Is For
Для чего предназначен этот мини-проект

Этот мини-проект предоставляет готовую версию способа отладки с помощью `printf()` через UART1, введённого в проекте 07.

Отдельная версия UART1 полезна, когда UART0 уже используется, когда проекту нужны два последовательных канала или когда отладочный вывод нужно отделить от другого канала связи.

После перенаправления `stdout` в UART1 функция `printf()` позволяет выводить:

- значения переменных;
- счётчики;
- показания АЦП;
- результаты вычислений;
- сообщения о состоянии;
- сообщения об ошибках;
- диагностическую информацию.

Это удобнее, чем вручную преобразовывать каждое значение в отдельные байты UART.

## Usage Options
Варианты использования

Можно:

- выводить несколько переменных в одной строке;
- отображать целые значения в десятичном или шестнадцатеричном виде;
- заменить сообщение со счётчиком собственным диагностическим текстом;
- изменить интервал передачи 500 мс;
- выбрать другую поддерживаемую стандартную скорость передачи; при её изменении также измените настройку UART на сайте **uartdebug.com**;
- использовать UART0 и UART1 для разных задач в более крупном проекте;
- изменить частоту CPU, как показано в проекте 02; обновите `F_CPU` в этом проекте в соответствии с новой частотой.

## Common Mistakes
Распространённые ошибки

- Подключение принимающего адаптера USB-UART к `PB2` вместо `PA1`.
- Ошибка, при которой забывают, что этот проект использует UART1, а не UART0.
- Отсутствие перенаправления `stdout`.
- Подключение `TxD` микроконтроллера к `TxD` адаптера вместо `RxD`.
- Отсутствие общего `GND`.
- Использование разных уровней логического напряжения.
- Выбор неправильного COM-порта.
- Выбор одного и того же COM-порта для обоих адаптеров.
- Выбор неправильной скорости передачи.

## Code Description
Описание кода

### Main Compiler Header
Основной заголовочный файл компилятора

`#include <xc.h>` предоставляет определения регистров и битов конкретного устройства для XC8.

### Standard I/O Library
Стандартная библиотека ввода-вывода

```c
#include <stdio.h>
```

Этот заголовочный файл предоставляет стандартный тип `FILE` и объявление функции `printf()`.

### CPU Clock Definition
Определение частоты процессора

```c
#define F_CPU 3333333UL
```

`F_CPU` используется библиотекой задержек и при расчёте скорости UART.

При заводских настройках тактирования частота процессора составляет приблизительно 3,333 МГц.

Эта директива не настраивает аппаратную частоту.

### Delay Library
Библиотека задержек

```c
#include <util/delay.h>
```

Этот заголовочный файл предоставляет `_delay_ms()` и `_delay_us()`.

`F_CPU` должна быть определена до подключения этого заголовочного файла.

### User-Defined UART Parameters
Параметры UART, задаваемые пользователем

```c
#define BAUD_RATE 115200UL
#define CLK_PER   F_CPU
```

`BAUD_RATE` выбирается пользователем.

`CLK_PER` — частота периферийного тактирования, используемая при расчёте скорости. Здесь она равна `F_CPU`.

### USART Baud Register Calculation
Расчёт регистра скорости USART

```c
#define USART_BAUD_RATE \
    ((uint16_t)(((float)CLK_PER * 64.0 / (16.0 * (float)BAUD_RATE)) + 0.5))
```

Это выражение рассчитывает значение, записываемое в `USART1.BAUD`.

Вычисление с плавающей точкой и добавление `0.5` округляют результат до ближайшего целого.

### printf Character Output Function
Функция вывода символа для printf

```c
int USART_PrintChar(char c, FILE *stream)
```

Эта функция вызывается перенаправленным стандартным потоком вывода каждый раз, когда `printf()` передаёт символ.

Аргумент `stream` требуется интерфейсом стандартного потока. В этом примере функция больше его не использует.

### Data Register Empty Check
Проверка освобождения регистра данных

```c
while (!(USART1.STATUS & USART_DREIF_bm))
{
    ;
}
```

Этот цикл опроса ожидает, пока буфер передачи USART1 сможет принять следующий байт.

Поскольку передача блокирующая, выполнение программы остаётся здесь до готовности передатчика.

### Character Transmission
Передача символа

```c
USART1.TXDATAL = c;
```

Эта операция записывает один символ, сформированный `printf()`, в регистр данных передатчика USART1.

### printf Output Stream
Выходной поток printf

```c
FILE USART_stream = FDEV_SETUP_STREAM(USART_PrintChar, NULL, _FDEV_SETUP_WRITE);
```

Эта строка создаёт стандартный поток ввода-вывода только для записи, функцией вывода символа которого является `USART_PrintChar()`.

### USART1 Initialization
Инициализация USART1

Функция `USART_Init()` настраивает UART1 и перенаправляет `stdout`.

#### UART Frame Format
Формат кадра UART

Присваивание `USART1.CTRLC` выбирает асинхронный режим, отсутствие чётности, 8 бит данных и 1 стоповый бит: `8N1`.

#### USART Baud Rate Register
Регистр скорости USART

```c
USART1.BAUD = USART_BAUD_RATE;
```

Этот регистр настраивает генератор скорости USART. При текущей частоте тактирования и значении `BAUD_RATE` обеспечивается скорость приблизительно 115200 бод.

#### UART1 TxD Pin Configuration
Настройка вывода TxD UART1

```c
PORTA.DIRSET = PIN1_bm;
```

PA1 настраивается как выход передачи UART1.

Для микроконтроллеров tinyAVR 2-series в корпусах SOIC-14 сигнал `PA1` находится на выводе 11.

#### USART Transmitter Enable
Разрешение передатчика USART

```c
USART1.CTRLB = USART_TXEN_bm;
```

Эта операция разрешает передатчик USART1.

#### stdout Redirection
Перенаправление stdout

```c
stdout = &USART_stream;
```

Эта операция перенаправляет стандартный вывод в ранее созданный поток USART.

После этого вызовы `printf()` используют `USART_PrintChar()` для передачи своих символов.

### UART1 Initialization Note
Примечание об инициализации UART1

Для преобразования примера в UART1:

1. Замените `USART1.` на `USART1.`.
2. Замените `PORTA.DIRSET = PIN1_bm;` на `PORTA.DIRSET = PIN1_bm;`.

Для предполагаемых микроконтроллеров tinyAVR 2-series в корпусе SOIC-14 сигнал `TxD` UART1 находится на `PA1`, вывод 11.

Точка входа

`int main(void)` — точка входа программы.

uint16_t tr_count = 0;

Эта переменная хранит значение счётчика, выводимого функцией `printf()`.

Вызов инициализации USART1

```c
USART_Init();
```

UART1 настраивается, а `stdout` перенаправляется до запуска главного цикла.

### Main Infinite Loop
Главный бесконечный цикл

Цикл `while (1)` непрерывно выводит и увеличивает счётчик.

### Formatted Text Transmission
Передача форматированного текста

```c
printf("Counter = %u\r\n", tr_count);
```

Эта функция форматирует текущее значение `tr_count` как беззнаковое десятичное число и передаёт полученные символы через перенаправленный поток `stdout`.

`\r\n` завершает строку текста.

### Counter Increment
Увеличение счётчика

```c
tr_count++;
```

Эта операция увеличивает счётчик после каждой переданной строки.

### Transmission Interval
Интервал передачи

```c

```

Эта функция создаёт интервал приблизительно 500 мс между выводимыми строками и блокирует главный цикл во время задержки.
