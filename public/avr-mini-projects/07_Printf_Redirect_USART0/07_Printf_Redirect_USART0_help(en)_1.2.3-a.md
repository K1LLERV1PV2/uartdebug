# 07_Printf_Redirect_USART0

## File Version

Version 1.2.3-a

## Short Project Description

Redirect `printf()` output to UART0 for blocking formatted-text transmission.

## Full Mini-Project Description

This mini-project initializes UART0 and redirects the standard C `stdout` stream to it.

After this redirection, text produced by `printf()` is transmitted through UART0. The example sends an incrementing counter every 500 ms:

```text
Counter = 0
Counter = 1
Counter = 2
...
```

The project uses blocking UART transmission. Each character produced by `printf()` is passed to `USART_PrintChar()`, which waits until the USART transmit buffer can accept another byte and then writes the character to `USART0.TXDATAL`.

UART format:

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

Common notation:

```text
115200 8N1
```

The received text can be observed in the UART section of **uartdebug.com**.

## Hardware Requirements and Setup

The intended setup uses two USB-UART adapters:

- one adapter for UPDI programming;
- a second adapter for receiving and displaying the UART0 text generated by `printf()`.

The second adapter connections:

```text
Microcontroller PB2 / TxD  ->  USB-UART RxD
Microcontroller GND        ->  USB-UART GND
```

The microcontroller and the receiving USB-UART adapter should use the same logic voltage level.

For tinyAVR 2-series devices in SOIC-14 packages, `PB2` is pin 7.

The microcontroller’s `RxD` pin is not used in this mini-project.

## What This Mini-Project Is For

This mini-project demonstrates how to use `printf()` as a simple software debugging tool.

After `stdout` is redirected to UART0, the same familiar `printf()` function can display:

- variable values;
- counters;
- ADC readings;
- calculated results;
- status messages;
- error messages;
- diagnostic information.

This is more convenient than manually converting every value into individual UART bytes.

## Usage Options

You can:

- print several variables in one line;
- display integer values in decimal or hexadecimal form;
- replace the counter message with your own diagnostic text;
- change the 500 ms transmission interval;
- select another supported standard baud rate; when changing it, also change the UART setting in **uartdebug.com**;
- use UART1 instead of UART0; this requires code changes and connection of the second adapter to the UART1 transmit pin;
- change the CPU frequency as demonstrated in Project 02; update `F_CPU` in this project to match the new frequency.

## Common Mistakes

- Forgetting to redirect `stdout`.
- Connecting microcontroller `TxD` to adapter `TxD` instead of adapter `RxD`.
- Forgetting common `GND`.
- Using different logic voltage levels.
- Selecting the wrong COM port.
- Selecting the same COM port for both adapters.
- Selecting the wrong baud rate.

## Code Description

### Main Compiler Header

`#include <xc.h>` provides device-specific register and bit definitions for XC8.

### Standard I/O Library

```c
#include <stdio.h>
```

This header provides the standard `FILE` type and `printf()` declaration.

### CPU Clock Definition

```c
#define F_CPU 3333333UL
```

`F_CPU` is used by the delay library and the UART baud-rate calculation.

With the factory clock settings, the CPU frequency is approximately 3.333 MHz.

This definition does not configure the hardware clock.

### Delay Library

```c
#include <util/delay.h>
```

This header provides `_delay_ms()` and `_delay_us()`.

`F_CPU` must be defined before including this header.

### User-Defined UART Parameters

```c
#define BAUD_RATE 115200UL
#define CLK_PER   F_CPU
```

`BAUD_RATE` is selected by the user.

`CLK_PER` is the peripheral clock used in the baud calculation. Here it equals `F_CPU`.

### USART Baud Register Calculation

```c
#define USART_BAUD_RATE \
    ((uint16_t)(((float)CLK_PER * 64.0 / (16.0 * (float)BAUD_RATE)) + 0.5))
```

This expression calculates the value written to `USART0.BAUD`.

The floating-point expression and `+ 0.5` round the result to the nearest integer.

### printf Character Output Function

```c
int USART_PrintChar(char c, FILE *stream)
```

This function is called by the redirected standard output stream whenever `printf()` sends a character.

The `stream` argument is required by the standard stream interface. The function does not otherwise use it in this example.

### Data Register Empty Check

```c
while (!(USART0.STATUS & USART_DREIF_bm))
{
    ;
}
```

This polling loop waits until the USART0 transmit buffer can accept another byte.

Because transmission is blocking, program execution remains here until the transmitter is ready.

### Character Transmission

```c
USART0.TXDATAL = c;
```

This writes one character produced by `printf()` to the USART0 transmit data register.

### printf Output Stream

```c
FILE USART_stream = FDEV_SETUP_STREAM(USART_PrintChar, NULL, _FDEV_SETUP_WRITE);
```

This creates a write-only standard I/O stream whose character-output function is `USART_PrintChar()`.

### USART0 Initialization

`USART_Init()` configures UART0 and redirects `stdout`.

#### UART Frame Format

The `USART0.CTRLC` assignment selects asynchronous mode, no parity, 8 data bits, and 1 stop bit: `8N1`.

#### USART Baud Rate Register

```c
USART0.BAUD = USART_BAUD_RATE;
```

This register configures the USART baud-rate generator. With the current clock and `BAUD_RATE` settings, it provides approximately 115200 baud.

#### UART0 TxD Pin Configuration

```c
PORTB.DIRSET = PIN2_bm;
```

PB2 is configured as the UART0 transmit output.

For tinyAVR 2-series devices in SOIC-14 packages, `PB2` is pin 7.

#### USART Transmitter Enable

```c
USART0.CTRLB = USART_TXEN_bm;
```

This enables the USART0 transmitter.

#### stdout Redirection

```c
stdout = &USART_stream;
```

This redirects standard output to the previously created USART stream.

After this assignment, calls to `printf()` use `USART_PrintChar()` to transmit their characters.

### UART1 Initialization Note

To convert the example to UART1:

1. Replace `USART0.` with `USART1.`.
2. Replace `PORTB.DIRSET = PIN2_bm;` with `PORTA.DIRSET = PIN1_bm;`.

For the intended SOIC-14 tinyAVR 2-series devices, UART1 `TxD` is `PA1`, pin 11.

### The Entry Point

`int main(void)` is the program entry point.

### Transmission Counter Variable

```c
uint16_t tr_count = 0;
```

This variable stores the counter printed by `printf()`.

### USART0 Initialization Call

```c
USART_Init();
```

UART0 is configured and `stdout` is redirected before the main loop starts.

### Main Infinite Loop

The `while (1)` loop continuously prints and increments the counter.

### Formatted Text Transmission

```c
printf("Counter = %u\r\n", tr_count);
```

This formats the current `tr_count` value as unsigned decimal text and sends the resulting characters through the redirected `stdout` stream.

`\r\n` terminates the text line.

### Counter Increment

```c
tr_count++;
```

This increments the counter after each transmitted line.

### Transmission Interval

```c
_delay_ms(500);
```

This creates an interval of approximately 500 ms between printed lines and blocks the main loop during the delay.

### Application Scope

This mini-project is intended for tinyAVR 2-series devices with compatible USART and pin-routing registers and an XC8 standard I/O implementation supporting `FDEV_SETUP_STREAM`.
